## 3. 🗑️ Zone de danger : choix de la portée du reset
Paramètres → Zone de danger : 2 options radio (commit `1865713`).
- **Données financières uniquement** (comportement d'avant) : additions/commandes, dépenses (dont récurrentes), rentrées.
- **Toutes les données stockées** (nouveau) : tout (commandes, clients, personnel, carte, stocks, fournisseurs, livraisons, biens, événements…) **sauf les comptes utilisateurs**.
- Serveur : `POST /api/reset-financial` accepte `{ scope: 'financial' | 'all' }` (défaut financial), super admin uniquement. Nouvelle query `resetAllData()`.

## 4. 🖥️ Application desktop .exe — PostgreSQL EMBARQUÉ (zéro installation)
**L'utilisateur double-clique le `.exe` et ça marche, sans rien installer** (commits `2ae095e`, `567ff58`). Voir `DESKTOP-APP.md` et [[desktop-electron-app]].
- Paquet **`embedded-postgres`** (binaires Windows inclus car `asar:false`). `electron/main.cjs` démarre un Postgres portable sur le port **54329**, données dans **`%APPDATA%/RestoPilote/pgdata`** (persistantes ; `app.setName('RestoPilote')`), crée la base `chefsuite`, puis lance le serveur.
- `server.ts` applique les **migrations Drizzle** au boot si `RUN_MIGRATIONS=true` (crée les tables) — isolé du web (Render/Neon, dev local via db:push).
- **Validé de bout en bout** sur la machine : l'exe packagé démarre PG 18.4 + migrations (tables créées) + `/api/health` OK. **Installateur ~137 Mo** régénéré avec le code à jour → **`C:\Users\USER\Desktop\RestoPilote Setup 0.0.0.exe`**.
- ⚠️ **Piège EPERM** au build (`release\win-unpacked.tmp`, Defender/« Accès contrôlé aux dossiers » sur `D:\perso`). **Contournement fiable** : `npm run build` puis `npx electron-builder --win -c.directories.output="$env:LOCALAPPDATA\Temp\restopilote-release"`. Fix permanent : exclusion Defender sur le dossier projet.
- ⚠️ **Orphelins** : si l'app est **tuée de force**, `postgres.exe` peut rester (port 54329 occupé) → **redémarrer le PC** avant de relancer le nouvel .exe. (Des orphelins de test tournent actuellement sur cette machine.)
- Après un changement de `src/db/schema.ts` : `npm run db:generate` avant de rebâtir le `.exe`.
